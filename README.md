# SageBot

SageBot is a lightweight utility written in C, designed to prevent being disconnected for inactivity (AFK) in VALORANT.

## How to use?
1. [Download here.]([https://github.com/18mzu/sagebot/releases/tag/release](https://github.com/18mzu/sagebot/releases/tag/v2.1))
2. Run sagebot.exe
